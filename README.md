# Airbnb Strategic Intel

**Smart Forecasting & ROI Analytics Powered by Geospatial + Economic Data**  
A Machine Learning-Powered Decision Support Framework for Airbnb Hosts and Guests  
Developed by **Jay Jignesh Pandya**, **Dhruv Punmiya**, and **Veer Jani**


## 🔍 Overview

**Airbnb Strategic Intel** is a data-driven dashboard designed to empower Airbnb stakeholders with actionable insights. From rental price forecasting to ROI analysis, our platform helps both **guests** and **hosts** make informed decisions based on real-time data, economic indicators, and location intelligence.

With NYC as our pilot region, the system integrates **machine learning**, **geospatial visualization**, and **macroeconomic APIs** to tackle key rental market challenges — pricing transparency, profitability forecasting, and investment risk.

## 🧠 Key Features

### 🧳 Guest-Focused Tools
- 📆 **Seasonal Price Predictions**
- 🧮 **Inflation-Adjusted Affordability Metrics**
- 🏙️ **Neighborhood Price Fairness Score**
- 🎯 **Amenity and Location-Based Filtering**

### 🏠 Host-Focused Tools
- 💰 **ROI Calculator**
- ⚖️ **Breakeven Analysis (CapEx + OpEx)**
- 📊 **Dynamic Profitability Forecast**
- 📈 **Macroeconomic-Aware Pricing Suggestions** (GDP & CPI-driven)

## 🚀 Core Technologies

| Layer               | Stack Used                                                  |
|--------------------|-------------------------------------------------------------|
| Machine Learning    | `XGBoost`, `scikit-learn`, `pandas`                         |
| Geospatial Mapping  | `GeoPandas`, `Folium`, `Shapely`                            |
| Visualization       | `Matplotlib`, `Seaborn`, `Plotly`                           |
| Economic Data       | Real-time REST APIs for **GDP** and **CPI**                |
| Development Env     | `Jupyter Notebook`, `Python 3.x`                           |
| Data Sources        | Kaggle’s `AB_NYC_2019`, Inside Airbnb `listings.csv`       |

## 🌐 Data & Scope

- **Region:** New York City (pilot implementation)
- **Scalability:** Designed for future global rollout
- **Data Layers:**
  - Airbnb listing features (price, reviews, location, amenities)
  - External economic indicators (CPI, GDP growth)
  - Geospatial cluster segmentation for neighborhoods

## 📈 Model Highlights

We implemented **XGBoost** due to its:
- High performance on structured data
- Ability to handle nonlinear feature relationships
- Interpretability via feature importance and SHAP values

The model forecasts seasonal rental prices while factoring in:
- Location
- Amenities
- Historical trends
- Economic context (GDP/CPI)
